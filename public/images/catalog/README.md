# Catalog artwork

Place artwork you own or are authorized to use in this folder. The prepared configuration expects `movie-1.jpg` through `movie-4.jpg` and `series-1.jpg` through `series-4.jpg`.

Keep artwork vertical with an aspect ratio close to 2:3, then update the title, year, type and image path in `lib/catalog.ts`. Missing files automatically use `fallback-poster.svg` and never display a broken image.
